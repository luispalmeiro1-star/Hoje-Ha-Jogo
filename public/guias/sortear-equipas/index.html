Sortear equipas de futebol

Escreve os nomes, um por linha, e carrega em sortear. Sai uma divisão ao acaso em equipas do mesmo tamanho, pronta para copiar para o grupo.

Como funciona

  1. Cola ou escreve os nomes. Podes colar uma lista numerada do WhatsApp: os números são ignorados.
  2. Escolhe quantas equipas queres: 2, 3 ou 4.
  3. Carrega em Sortear equipas. Se não gostares, carrega outra vez.
  4. Carrega em Copiar para o WhatsApp e cola no grupo.

O sorteio é feito no teu telemóvel. Os nomes não são enviados para lado nenhum.

Sorteio ou capitães?

Os capitães a escolher têm um problema conhecido: há sempre alguém que fica para o fim. O sorteio é mais rápido e ninguém leva a mal. O risco é sair uma equipa muito mais forte. Quando isso acontece, sorteia outra vez ou troca dois jogadores à mão.

E os guarda-redes?

Se só houver dois guarda-redes, não os ponhas no sorteio: mete um em cada equipa e sorteia os restantes. Se ninguém quiser ir à baliza, a regra mais usada é rodar a cada golo sofrido ou a cada cinco minutos.

Sortear todas as semanas, sem escrever os nomes

Se o jogo é semanal, escrever a lista de cada vez cansa. Na Hoje Há Jogo as equipas são sorteadas a partir de quem confirmou presença, e o admin pode ajustar à mão antes do jogo.

Perguntas frequentes

Como sortear equipas de futebol de forma justa?

Mistura os nomes ao acaso e distribui-os alternadamente pelas equipas, para ficarem do mesmo tamanho. Se uma equipa ficar muito mais forte, repete o sorteio ou troca dois jogadores.

Este sorteador de equipas é grátis?

Sim. Não precisa de conta nem de instalar nada, e os nomes ficam só no teu telemóvel.

Posso sortear três ou quatro equipas?

Sim. Escolhe o número de equipas antes de sortear. Precisas de pelo menos dois jogadores por equipa.

A Hoje Há Jogo trata disto por ti. Cada um responde VOU ou NÃO VOU e a lista faz-se sozinha.
